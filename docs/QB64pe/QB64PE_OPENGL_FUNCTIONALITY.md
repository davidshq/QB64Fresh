# QB64pe OpenGL Functionality — Complete List

**Source:** QB64pe parses `internal/c/parts/core/gl_header_for_parsing/gl.h` at startup and registers all `WINGDIAPI ... APIENTRY gl*` functions and `#define GL_*` constants. The single GLU entry is added in `source/subs_functions/extensions/opengl/opengl_methods.bas` (`gl_include_content`). QB64pe-specific statements (`_GLRENDER`, `_GLCOMPAT`, `SUB _GL`) are defined elsewhere.

**Summary:**

| Category | Count | QB64 BASIC name |
|----------|-------|-----------------|
| OpenGL functions/subs (from gl.h) | 312 | `_GL*` (e.g. `_GLBEGIN`, `_GLVERTEX3F`) |
| GLU (hand-added) | 1 | `_GLUPERSPECTIVE` |
| GL constants (from gl.h) | 590 | `GL_*` or `_GL_*` (e.g. `GL_TRIANGLES`, `_GL_TRIANGLES`) |
| QB64pe-specific | 3 | `SUB _GL`, `_GLRENDER`, `_GLCOMPAT` |

---

## 1. QB64pe-specific (not in gl.h)

| Item | Type | Description |
|------|------|-------------|
| `SUB _GL` | Subroutine | The only place where `_GL*` / `_GLU*` commands are allowed. Called by the runtime when the display is updated (e.g. vsync). Cannot be called directly from BASIC. |
| `_GLRENDER` | Statement | Syntax: `_GLRENDER _BEHIND` \| `_ONTOP` \| `_ONLY`. Controls whether OpenGL draws behind, on top of, or instead of the 2D layer. |
| `_GLCOMPAT` | Function | Returns whether OpenGL is available (e.g. 1 if GL context is present, 0 otherwise). |

---
