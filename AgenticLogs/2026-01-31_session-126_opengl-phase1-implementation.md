# Session 126: OpenGL Phase 1 Implementation

**Date:** 2026-01-31

## Summary

Implemented **Phase 1** of the OpenGL/GLUT design ([OPENGL_GLUT_DESIGN.md](../ThingsToDo/OPENGL_GLUT_DESIGN.md)): `uses_opengl` detection, `--opengl`/`--no-opengl` CLI flags, and emission of `#define QB64FRESH_OPENGL` in generated C when OpenGL is used.

## Accomplished

### Phase 1 (complete)

1. **Detection** (`src/codegen/c_backend/analysis.rs`)
   - `program_uses_opengl(program)` — returns true if the program defines `SUB _GL` or calls any `_GL*` sub/function.
   - Recursive `statement_uses_opengl(stmt)` and `expr_uses_opengl(expr)` over typed IR (SubDefinition `_GL`, Call/FunctionCall names starting with `_GL`, nested statements/expressions).

2. **CLI** (`src/main.rs`)
   - `--opengl` — force OpenGL code emission.
   - `--no-opengl` — disable OpenGL even if source uses SUB _GL / _GL*.
   - Default: `uses_opengl = program_uses_opengl(&typed_program)` unless overridden.

3. **Backend** (`src/codegen/c_backend/mod.rs`)
   - `CBackend` field `uses_opengl: bool` and `with_opengl(enabled)`.
   - When generating C, pass `uses_opengl` to `emit_header_with_debug`.

4. **Header** (`src/codegen/c_backend/runtime/mod.rs`)
   - `emit_header_with_debug(..., uses_opengl: bool)`.
   - When `uses_opengl`, emit `#define QB64FRESH_OPENGL 1` after the "Generated by QB64Fresh" comment.

5. **Re-export**
   - `program_uses_opengl` re-exported from `codegen` for use in main.

### Verification

- Program with `SUB _GL` and `_GLRENDER _ONTOP` → generated C contains `#define QB64FRESH_OPENGL 1`.
- Program with only `PRINT "hello"` → no `QB64FRESH_OPENGL` in generated C.
- `--no-opengl` on OpenGL-using source → no `QB64FRESH_OPENGL`.
- `--opengl` on non-OpenGL source → `#define QB64FRESH_OPENGL 1`.
- `cargo test` passes.
